27 November 2026 · 390px mobile and 1440px desktop

The shortlist covers four established multi-category retailers with menswear ranges and one direct menswear fabric specialist. Category relevance and storefront execution informed the shortlist. The five entries have no implied sales or traffic ranking. The audit used rendered first-screen captures, five scroll positions at each viewport width, computed heading sizes and footer inspection. Campaigns are time-sensitive. J.'s region and consent overlays and Dynasty's newsletter overlay obscured portions of their first screens. Sapphire exposed limited computed campaign-heading data, so its first-screen hierarchy is described visually.

## Implemented hierarchy

- **Hero first.** The campaign headline is the first text in the hero, followed by category, description and the shopping action. The title scales continuously from 36px to 92px across the tested viewport range. Section headings run from about 27px to 48px and collection names from about 15px to 25px.
- **One set of page edges.** Brand mark, hero text, collection heading, buying assurances, order help and footer content begin on the same left rail. Desktop navigation is centered, with search on the right. Mobile tabs are equal width and use the same column gaps as the three collection cards.
- **Shared collection rows.** Images, names, descriptions, prices, actions and swatches have shared row tracks where supported. Longer names and different swatch counts can wrap without shifting neighboring price and action rows. Mobile keeps all three collection cards in one row.
- **A clear close.** Delivery facts use three equal cells. The order-help heading and FAQ have a deliberate desktop split and stack on phones. Desktop footer groups return to the three-column grid.

Verification covers type order, section rails, shared collection rows, viewport overflow, search and the collection CTA. This is a visual hierarchy audit. Conversion impact is unmeasured.
